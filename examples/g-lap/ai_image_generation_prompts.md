## Production Checklist

Before generating, verify each image against these rules:

- [ ] Dark graphite background (#2D2D2D range) — no exceptions
- [ ] Only specified accent colors used (teal, amber, crimson) — no rogue hues
- [ ] No glowing AI brains, neural networks, or particle effects
- [ ] No readable real text baked in (use abstract text blocks or leave overlay zones)
- [ ] 16:9 aspect ratio maintained
- [ ] Flat/matte surfaces — no glossy 3D renders
- [ ] Editorial documentary tone — not startup ad, not sci-fi, not SaaS marketing
- [ ] Teal = AI/active pathways only
- [ ] Amber = governance/approval/human checkpoint only
- [ ] Crimson = risk/conflict/problem only (appears in IMG-S07-A and IMG-S10-A only)
- [ ] AI is never shown as autonomous magic — always paired with boundaries, evidence, or review UI
- [ ] Founder images are candid/composed, never heroic
